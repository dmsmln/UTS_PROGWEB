# Project UTS — Website Profil Kopi Senja

Website statis profil UMKM kopi fiktif menggunakan HTML dan CSS. Dibuat untuk latihan/tugas, sehingga nama usaha, alamat, menu, dan harga dapat diedit sesuai kebutuhan.

## Isi folder

- `index.html` — halaman utama, profil singkat, gambar, dan nilai usaha.
- `produk.html` — tabel menu dan harga produk.
- `kontak.html` — profil, visi-misi, informasi kontak dan jam operasional.
- `css/style.css` — seluruh aturan tampilan dan responsif.
- `assets/kopi-senja.svg` — ilustrasi lokal yang dipakai sebagai gambar.
- `screenshots/` — contoh tangkapan layar halaman website.

## Cara membuka

1. Ekstrak folder project.
2. Buka `index.html` dengan browser seperti Chrome.
3. Coba navigasi **Beranda**, **Produk**, dan **Tentang & Kontak** untuk memastikan hyperlink bekerja.

## Cara mengganti isi

- Ganti nama usaha dan profil di file HTML.
- Ubah baris produk, deskripsi, ukuran, dan harga di tabel `produk.html`.
- Ubah alamat, email contoh, dan jam operasional di `kontak.html`.
- Warna, jarak, font, dan layout diatur dari `css/style.css`.

Alamat dan harga di proyek ini adalah contoh fiktif. Ubah agar sesuai dengan instruksi dosen atau ide kelompokmu.

## Cara hosting gratis dengan GitHub Pages

1. Login ke GitHub, lalu klik **New repository**.
2. Beri nama repo, misalnya `uts-website-kopi-senja`, lalu buat repository.
3. Upload seluruh isi folder ini ke root repository. Pastikan `index.html` berada di root, bukan di dalam folder lain.
4. Buka **Settings → Pages**.
5. Pada bagian **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
6. Tunggu proses publikasi selesai dan buka URL yang ditampilkan pada menu Pages.
7. Uji semua halaman dan gambar dari URL publik tersebut.

## Rencana video demo 5–10 menit

1. (0:00–1:00) Perkenalan project dan tujuan website Kopi Senja.
2. (1:00–2:30) Demonstrasi halaman Beranda: header, navigasi, gambar, profil, dan bagian nilai usaha.
3. (2:30–4:00) Buka halaman Produk dan jelaskan tabel menu, deskripsi, ukuran, harga, `table`, `thead`, `tbody`, `tr`, `th`, dan `td`.
4. (4:00–5:30) Buka halaman Tentang & Kontak dan jelaskan profil, visi-misi, dan kontak.
5. (5:30–7:30) Jelaskan tag HTML: `header`, `nav`, `main`, `section`, `article`, `footer`, `a`, `img`, dan penggunaan `div` sebagai pembungkus layout.
6. (7:30–9:00) Jelaskan CSS di `css/style.css`: variabel warna, layout Grid/Flexbox, jarak, warna, hover, dan media query untuk tampilan mobile.
7. (9:00–9:30) Tunjukkan website melalui URL GitHub Pages jika sudah di-host.

Sesuaikan durasi dengan cara bicaramu; yang terpenting semua bagian tugas dijelaskan dengan jelas.
